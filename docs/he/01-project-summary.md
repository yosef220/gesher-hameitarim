# גשר — סיכום הפרויקט

> נכון ל-25.11.2026, לפי `gesher-runtime/gesher` (main בקומיט `669d40a12`), הגרסה הרשמית 0.2.0 והפורק `Lev-Good/gesher` ‏(v0.2.0-lev1).

## מה זה גשר

גשר מריץ אפליקציות אנדרואיד על Windows **כתוכנות Windows רגילות, בלי אמולטור ובלי מכונה וירטואלית**. פותחים קובץ ‎`.apk` בלחיצה כפולה, והאפליקציה רצה בחלון רגיל.

הרעיון דומה ל-Wine, רק בכיוון ההפוך. גשר לא כותב את אנדרואיד מחדש. הוא מהדר ל-Windows את הקוד האמיתי של אנדרואיד (AOSP, גרסה `android-16.0.0_r4`): את מנוע ה-Java ‏(ART), את ה-framework ואת מנוע הציור. רק השכבות שמדברות ישירות עם הקרנל של לינוקס מוחלפות.

**עקרונות הפרויקט:** אין VM, ותהליך Windows אחד לכל אפליקציה. כשאין אפליקציה פתוחה, שום דבר לא רץ. אין חנות, פותחים קבצי APK שכבר יש למשתמש. הרשת והתעודות הן של Windows עצמה, ולכן סינון תוכן ופרוקסי ארגוני עובדים בלי הגדרה.

## איך זה עובד — השכבות

```
 ‎.apk ◄── מטען APK        מניפסט, משאבים, dex, ספריות נייטיב
         ART (עם JIT)     מנוע ה-Java של אנדרואיד, מוסב ל-Windows
         framework.jar    ה-framework האמיתי של אנדרואיד
           └ שירותי מערכת ממומשים בתוך התהליך (במקום system_server)
         HWUI + Skia      ← OpenGL ES ← ANGLE ← Direct3D 11
         ספריות ‎.so       מטען ELF + ‏bionic על Win32 (+ תרגום arm64)
         שילוב בשולחן העבודה  חלונות, קלט, IME, לוח העתקה, קבצים, התראות
```

| רכיב | תפקיד | המימוש ב-Windows |
|---|---|---|
| **gesher-base** | הפונקציות של לינוקס ש-ART צריך | `mmap` מעל `VirtualAlloc`, ‏futex מעל `WaitOnAddress`, ‏SIGSEGV מעל vectored exceptions, ‏`/proc` מסונתז |
| **ART** | הרצת קוד Java/Kotlin | ART של AOSP עם 100 טלאים (תיקיית `patches/`) |
| **שירותי מערכת** | PackageManager, ActivityManager, WindowManager ועוד | מימוש בתוך התהליך במקום Binder ל-system_server, בדומה ל-Robolectric |
| **גרפיקה** | HWUI ו-Skia | OpenGL ES דרך ANGLE מעל Direct3D 11 (כמו בכרום) |
| **ספריות נייטיב** | קבצי ‎`.so` של אפליקציות | מטען ELF משלו + ‏bionic על Win32. ספריות x86-64 רצות ישירות, ו-arm64 עובר תרגום בינארי (dynarmic) |
| **שילוב** | חלון לכל משימה, עכבר ועט כמגע, IME בעברית, לוח העתקה, קבצים, התראות | Win32, ‏Windows IME, ‏toasts, ‏WASAPI לשמע, ‏Media Foundation למדיה, ‏WebView2 ל-WebView |
| **שירותי Google** | אפליקציות שתלויות ב-Play services | microG (התקנה בלחיצה) ו-Aurora Store כחנות. Play Store המקורי לא נכלל |

## בנייה ותוצרים

- **הבנייה רצה על לינוקס או WSL ומפיקה קבצים ל-Windows x64**, עם llvm-mingw. מקורות AOSP מוצמדים נמשכים עם `tools/fetch-aosp.sh` לפי `aosp.lock`, ומוחלים עליהם הטלאים.
- **ה-CI עושה את כל העבודה הכבדה.** ב-GitHub Actions מוגדרות כ-127 משימות על Ubuntu וכ-74 משימות מטריצה, כולל Windows Server 2022/2025. מיזוג אוטומטי מתבצע דרך GitHub App ‏(`GESHER_BOT_*`) עם תווית `automerge`.
- **התוצרים:** `dalvikvm.exe` ‏(ART), ‏`gesher-exec.exe` (מארח ומשגר), מתקין `gesher-setup-X.Y.Z.exe` ‏(Inno Setup, התקנה למשתמש בלי הרשאות מנהל), וחבילה ניידת `gesher-X.Y.Z-portable.zip`.
- **עדכונים:** מרכז הבקרה בודק את GitHub Releases של upstream ומתקין עם אישור המשתמש.

## הממשק והעיצוב הנוכחי

| משטח | טכנולוגיה | מצב |

| **דיאלוגים נייטיב** | Win32/GDI עם `compat/windows/host_dialog_theme.h` | הרשאות, בחירת חשבון, הודעות קריסה, אישורים |

**השפה:** הממשק בעברית ובאנגלית לפי הגדרות השפה של Windows (`docs/ui-language.md`). המחרוזות נמצאות ב-`tools/i18n/messages.json`.

**הסגנון הנוכחי:** בהיר וגנרי. רקע `#F5F6F8`, כחול `#1570EF`, ‏Segoe UI ופינות של 6px בכל מקום, אותה פלטה במרכז הבקרה ובדיאלוגים הנייטיב. זה בדיוק "ערכת הכרטיסים של SaaS" שסקיל העיצוב שלנו מגדיר כברירת מחדל שצריך להימנע ממנה. בפורק של Lev-Good מרכז הבקרה כבר עוצב מחדש לפריסה דו-טורית בסגנון Fluent עם חיפוש חי.

## הפורק של Lev-Good ‏(v0.2.0-lev1)

"Gesher Custom Build" מה-24.11.2026. יש בו 7 קומיטים שלא קיימים ב-upstream, כולם בענף `fix/app-compat`:

1. תיקוני תאימות: `getPreviousName` ב-AccountManager (Google Play Games, אפליקציות Google), דילוג על authority מתנגש של ספק תוכן (בנק לאומי) וכינוי לשירות START_1P של Play Games עבור microG.
2. עיצוב מחדש של מרכז הבקרה: פריסה דו-טורית בסגנון Fluent וחיפוש אפליקציות חי.
3. נתיבי profman לשמות משתמש בעברית, דרך נתיב 8.3 (issue ‏#355).
4. ‏`mkfifo` עבור Realm, ומחוון הפעלה במרכז הבקרה.
5. לוגים והודעות חריגה מפורטים במתקין.
6. פרוקסי SOCKS5 דרך הגדרות Windows או `GESHER_PROXY`.

כל שאר הענפים בפורק הם העתקים של ענפי upstream.

## מגבלות ידועות

- **אין בידוד.** כל אפליקציה רצה בהרשאות של משתמש Windows. בידוד באמצעות AppContainer נמצא בפיתוח (PR ‏#427) וכבוי כברירת מחדל.
- **התאימות חלקית.** אפליקציות נכשלות על APIs חסרים, ספריות נייטיב ואורזי קוד.
- **אין 32 ביט.** אפליקציות `armeabi-v7a` לא רצות (מוביט ומזרחי טפחות מ"עוגן פליי").
- **אין Play Store** (במכוון). microG מתורגם לעברית רק בחלקו.
- **רשתות מסוננות** שמיירטות TLS שוברות אפליקציות עם הצמדת תעודות או HTTP/2.
- **פער שחרור:** משתמשים נתקלים בבאגים שכבר תוקנו ב-main, כי אין גרסה חדשה מאז 0.2.0.
