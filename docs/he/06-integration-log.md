לפני ההכנסה נבדקו ששת ה-PRs שמוזגו ב-upstream אחרי השינוי ברישיון מול עקרון התוצאות הכנות. בכולם השינוי כתוב לפי העיקרון ("לא ממומש, ולכן לא מדווח", ותחליף בדיקה מבודד מהקוד של המוצר).

**לא נכנסו:**
- `pr-484` הוצא מהתור. ‏`main` כבר מממש את הייצוא של `libstdc++.so` ב-`compat/bionic/cxx_bionic.cc` (מ-#432), ו-#484 הוסיף מימוש שני של אותן פונקציות.
- `pr-256` ממתין: ההתנגשויות שלו כוללות את הנעיצות בהכשרת המקורות, וצריך להפיק את שרשרת הנעיצות מחדש.
- `pr-475` ממתין: 75 מקטעים בהתנגשות מול #366 שב-`main`. צריך ענף נושא ייעודי.
- `pr-403` ו-`pr-427` ממתינים: מתנגשים ב-12 וב-22 קבצים.

**אימות:** ריצה [45723627516](https://github.com/yosef220/gesher-hameitarim/actions/runs/45723627516) **נכשלה**, ובוטלה לפני הסוף. בדיקות הזהות שתוקנו עברו הפעם. שלושה כשלים, כולם בפריטים החדשים:
- **javac:** ‏`SettingsProvider.addSecureDefault` הוגדרה פעמיים. גם `main` (זיהוי דיבור) וגם #451 (הקראה) הוסיפו אותה, במקומות שונים בקובץ, ולכן git מיזג בלי התנגשות. תוקן ב-`topic/pr-451`: הגדרה אחת. אחרי התיקון נסרקו כל קובצי ה-Java שהפריטים משנים, ולא נמצאה עוד מתודה שמוגדרת פעמיים.
- **הבדיקה של החבילה הניידת:** ‏#451 הוסיף את `gesher-tts.apk` למתקין, ותיקיית הבנייה המדומה בבדיקה לא כללה אותו. תוקן ב-`topic/pr-451`.
- **הכתוביות מול Windows אמיתי:** במכונות ה-CI ‏`get_ComputedRegionColor` מחזיר `E_INVALIDARG` כשהצבע והאטימות הם Default, ו-`captions::Read` נכשל כולו. תוקן ב-`topic/pr-468`: צבע מחושב נקרא רק כשהמיפוי משתמש בו. עובר קומפילציה וקישור ב-llvm-mingw. ההרצה על Windows תיבדק בריצה הבאה.

**אימות:** ריצה [45725332541](https://github.com/yosef220/gesher-hameitarim/actions/runs/45725332541) **נכשלה** בכשל אחד. מה שעבר בה מאמת את התיקונים הקודמים:

- **לא רץ:** החבילה, ה-e2e ושאר העבודות שתלויות ב-framework.
