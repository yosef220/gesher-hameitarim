# מרשם הבאגים — כל מה שדווח ב-GitHub

**מטרה:** לוודא שכל באג וכל בקשה שאנשים דיווחו עליהם מקבלים טיפול, תיקון ואימות. אף דיווח לא נשאר בלי סטטוס.

**מקור:** כל 49 ה-issues של `gesher-runtime/gesher` (17 פתוחים, 32 סגורים), כפי שנקראו ב-25.11.2026, מוצלבים מול הקוד: מה מוזג ל-main, מה נכנס לגרסה 0.2.0 ומה תקוע ב-PRs שלא מוזגו.

**הממצא המרכזי:** רוב התיקונים לבאגים שדווחו **כבר נמצאים ב-main של upstream, אבל לא בגרסה 0.2.0** שהמשתמשים מורידים. 102 PRs מוזגו אחרי 0.2.0 ולא שוחררו. לכן הגרסה הראשונה שלנו תפתור מיד חלק גדול מהדיווחים, עוד לפני כל עבודה חדשה.

## כללים

1. **אין "נסגר" בלי אימות.** issue מסומן אצלנו כפתור רק אחרי שעבר את שיטת האימות שלו בטבלה.
2. **אפליקציה שדווחה נכנסת לקורפוס.** כל אפליקציה שהוזכרה בדיווח נכנסת לקורפוס בדיקות ההפעלה ונבדקת בכל גרסה.
3. **דיווח חדש ← שורה חדשה.** כל issue חדש, אצלנו או ב-upstream, מקבל שורה במרשם תוך יום.
4. **מה שמחוץ לגשר מקבל עזרה, לא הסתרה.** כשהבעיה ברשת או בשרת חיצוני, אומרים את זה בעברית פשוטה ונותנים כלי לפתרון.
