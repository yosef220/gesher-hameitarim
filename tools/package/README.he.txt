גשר המיתרים — הפעלת יישומי Android ב־Windows
============================================

דרישות: Windows 10 או Windows 11 במחשב x64.
שפת הממשק של גשר המיתרים נבחרת אוטומטית לפי שפות התצוגה של Windows.
עברית ואנגלית נתמכות; אם אין תרגום מתאים, מוצג הממשק באנגלית.


על Gesher המקורי
----------------
גשר המיתרים מבוסס על Gesher, שיצר palmoni5. הוא פתח את הפרויקט באוקטובר 2026 וכתב את רובו
המכריע, עם תורמים נוספים. ב-25 בנובמבר 2026 עבר Gesher לרישיון קנייני והמאגר שלו נסגר.
גשר המיתרים ממשיך מהגרסה האחרונה שלו שפורסמה תחת Apache 2.0. תודה ל-palmoni5 ולכל מי שתרם.

אבטחה
-----
יישומי Android אינם מבודדים מ-Windows. גשר המיתרים מריץ כל יישום כתוכנה
רגילה של Windows, עם ההרשאות של חשבון ה-Windows שלך. בקשות ההרשאה של Android
קובעות מה יישום יכול לעשות דרך הממשקים של Android; הן אינן מונעות מהקוד שלו,
ובמיוחד מקוד native, לקרוא ולשנות את הקבצים שלך, להשתמש ברשת או להפעיל
תוכנות. יש להתייחס לקובץ APK כמו לקובץ EXE שהורד מהאינטרנט: להתקין רק
יישומים מהימנים, ממקורות מהימנים. בידוד לכל יישום (Windows AppContainer)
נמצא בפיתוח וכבוי.

עדכונים
-------
גשר המיתרים מתעדכן לבד. פעם ביום, כשפותחים יישום או את מרכז הבקרה, הוא בודק
אם יצאה גרסה חדשה, מוריד אותה ומוודא שהקובץ שלם ושהוא הקובץ שפורסם. ההתקנה
מתחילה רק כשאין יישום פתוח, כדי לא לסגור יישום באמצע עבודה:
סביבת גשר המיתרים נכבית לבד עשר דקות אחרי שהיישום האחרון נסגר, ואז העדכון
מותקן בשקט.
היישומים המותקנים והנתונים שלהם נשמרים, ואין צורך להסיר את התוכנה לפני עדכון.

ב״מרכז הבקרה של גשר המיתרים״ (בתפריט ״התחל״, או: gesher-app control-panel),
באזור העדכונים, אפשר לבדוק עדכון מיד, לכבות את ההתקנה האוטומטית (ואז כל
עדכון מחכה לאישור), או לכבות את הבדיקה האוטומטית לגמרי. מה שהעדכון האוטומטי
עשה נרשם ביומן:

    %LOCALAPPDATA%\Gesher\logs\update-agent.log

רשת מסוננת
-----------
העדכונים מגיעים מ־GitHub. ברשת מסוננת (למשל נטפרי או אתרוג) הבדיקה או ההורדה
עלולות להיחסם. אפשר לבקש מספק הסינון לאשר את הכתובות האלה:

    api.github.com
    github.com
    release-assets.githubusercontent.com
    objects.githubusercontent.com

גם הרכיבים האופציונליים של ההתקנה מורדים מהרשת: microG מ־github.com,
Aurora Store מ־auroraoss.com, ו־WebView2 מ־go.microsoft.com. כשהורדה נחסמת,
ההתקנה ממשיכה בלי הרכיב ומודיעה מה לא הותקן.

הפעלת יישומים
--------------
לחיצה כפולה על קובץ APK מתקינה או מעדכנת את היישום ומפעילה אותו בחלון.
אם קובצי APK משויכים לתוכנה אחרת, אפשר לבחור בגשר המיתרים מתוך ״פתח באמצעות״.
אפשר להתקין גם חבילות מפוצלות מסוג XAPK, APKS, APKM או APK+.

לכל יישום מותקן שיש לו מסך פתיחה נוצר קיצור דרך בתפריט ״התחל״,
בתיקיית ״יישומי גשר״, עם שם היישום והסמל שלו.

אפשר להשתמש גם בשורת הפקודה:

    gesher-app my.apk
    gesher-app install my.apk
    gesher-app launch com.example.app
    gesher-app list
    gesher-app uninstall com.example.app

סביבת גשר המיתרים
------------------
ההפעלה הראשונה מפעילה את סביבת גשר המיתרים ברקע. כל יישום פועל בתהליך נפרד,
והפעלות נוספות משתמשות באותה סביבה. סגירת החלון מסיימת את הפעילות.
הסביבה נעצרת אוטומטית לאחר עשר דקות ללא תהליך יישום פעיל.
אפשר לבדוק את מצבה או לעצור אותה במפורש:

    gesher-app status
    gesher-app shutdown

יישומים מותקנים והנתונים שלהם נשמרים בתיקייה:

    %LOCALAPPDATA%\Gesher\data

יומני האבחון נשמרים בתיקייה הבאה. היומנים הטכניים עשויים להיות באנגלית:

    %LOCALAPPDATA%\Gesher\logs

הכפתור "פתח את מיקום הלוגים" במרכז הבקרה פותח את תיקיית היומנים (בהתקנה ניידת: Data\logs שבתיקיית ההתקנה).

הרשאות, חשבונות ומצלמה
----------------------
גשר המיתרים מציג בקשת אישור לפני הענקת הרשאות רגישות או גישה לאסימון חשבון.
הבקשות מוצגות בעברית כשזו שפת המערכת. ברירת המחדל היא סירוב.
כשיישום מבקש לצלם תמונה, מצלמת גשר המיתרים מציגה את הכפתורים ״צילום תמונה״ ו״ביטול״.

תוכן אינטרנט ביישומים
---------------------
גשר המיתרים משתמש ב־Microsoft Edge WebView2 להצגת דפי אינטרנט בתוך יישומי Android.
הרכיב כלול ב־Windows 11 ובמחשבי Windows 10 מעודכנים. אם הוא חסר,
המתקין מציע להתקין אותו. נתוני האינטרנט של כל יישום נשמרים בנפרד.

הגדרות נוספות
--------------
אפשר לבחור פעילות מסוימת באמצעות ‎--activity .Other,
להפעיל ללא חלון באמצעות ‎--headless, או להגדיר שרת מתווך:

    gesher-app proxy host:port
    gesher-app proxy windows

הרחבות microG מאומתות מותקנות באמצעות gesher-app-microg.ps1.
הגדרת חשבונות, רישום המכשיר והודעות בענן נעשית בהגדרות microG עצמו.
שפתם של יישומי צד שלישי תלויה בתרגומים ובהגדרות שלהם.

דוגמת Java
-----------
להפעלת דוגמת Java המצורפת אפשר להריץ:

    gesher

להפעלת תוכנית שהומרה ל־DEX:

    gesher classes.dex com.example.Main

הסרת גשר המיתרים מסירה גם את הסביבה ואת נתוני היישומים שבתוכה.
